WHAT THIS APP IS
pew2 is a remote control for coding agents that run on your own computer. It is the phone half of a two part tool. The other half is a free command line program the user installs on their Mac, Windows or Linux machine with one command. The app has no accounts or hosted conversation database. An optional relay forwards encrypted session traffic, and remote notifications use Expo and Apple.

WHY THE APP SHOWS A PAIRING SCREEN ON FIRST LAUNCH
On launch the app asks you to scan a pairing code. That code is produced by the command line program on the user's own computer. Without a computer running it there is nothing for the app to connect to, in the same way a TV remote does nothing without a TV. This is the intended design and not a defect or a paywall.

HOW TO TEST IT
The fastest path, on any Mac, takes about a minute:

1. Open Terminal and run:
     curl -fsSL https://raw.githubusercontent.com/KenKaiii/pew2/main/install.sh | sh
2. Run:
     pew2 setup
   It finds any coding agents already installed, starts a local service, and prints a QR code.
3. Open pew2 on the device, tap Pair, and scan that QR code.

The app then shows the agents on that computer and you can start a conversation with one. If the computer has no coding agent installed, step 2 prints the command to install one.

If a reviewer would prefer a machine to be running and waiting so that only step 3 is needed, please reply to this note and one will be provided with a pairing code, at a time that suits the review.

ENCRYPTION
Traffic between the phone and the computer is end to end encrypted with XChaCha20-Poly1305 (the @noble/ciphers library, and Apple CryptoKit on iOS). Only standard cryptography is used and none of it is proprietary. When the two devices are not on the same network the traffic passes through a relay that can only see ciphertext.

PERMISSIONS
Camera is for scanning the pairing code and for taking a photo to send to an agent. Photos is for attaching an image and saving one an agent returns. Microphone is for dictating a message (speech recognition, on device) and for voice calls with Pew (audio goes to OpenAI during a call, after the user agrees). Notifications tell the user when an agent has finished or needs an answer. Prompts and attachments go to the user's chosen agent through the encrypted connection. With remote push registered, the computer sends finished-turn notifications through Expo to APNs even while the app is open. Expo and Apple handle the project or agent name, a short excerpt from the final response, a session identifier, and a push delivery address; these payloads are not end to end encrypted. Agent providers have their own data practices. The privacy policy and terms are accessible before pairing and in the connected app's connection sheet.

VOICE CALLS WITH PEW (AI)
Pew is an AI voice assistant (OpenAI Realtime). Before the first call the app shows "Pew is an AI. Your voice goes to OpenAI." with an "Agree and call" button (guideline 5.1.2(i)); the call screen labels it "Pew · AI" and Pew says it is an AI if asked. During a call the user's voice and a briefing about their own sessions go to OpenAI. pew2 records no audio; the user's own computer keeps the text of the last 20 exchanges per conversation (so a later call carries on), never sent to the developer, deleted after 30 days or with "Forget call history". The call uses the user's own OpenAI login from their computer (a 10 minute key is minted per call).

CALL-STYLE RINGS (PushKit / CallKit)
Optional, off by default. Pew rings the user like a phone call only when (1) they switched "Ring me" on for a limited time, (2) they allowed that specific conversation to ring, and (3) an agent there is stopped waiting on them (an approval or question). Every VoIP push is reported to CallKit; the computer decides whether to ring before sending, so no silent VoIP pushes are sent. Calls are not added to Recents. CallKit is disabled for China storefront users (a notification is shown instead). To see a ring: pair, open a conversation, hold the phone button, turn on "Ring for this chat", choose "1 hour" under Ring me, then ask the agent to do something that needs approval and lock the phone.
